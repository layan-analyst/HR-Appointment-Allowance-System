Appointment Allowance System – Wireframes

This folder contains editable wireframes for the HR Appointment Allowance Request Management System.

The wireframes illustrate the main system interfaces, including:

Appointment allowance request creation

Request tracking and correction

HR specialist review

HR manager approval or rejection

Summary reports

Conditional finance handoff

All wireframes are provided in Draw.io format and are based on the documented project requirements.

Note: The finance handoff interface is conditional and requires scope confirmation.
