# HR-Appointment-Allowance-System
Business Analysis portfolio project focused on improving and automating the HR appointment allowance request process


# Project Overview

This project is a fictional case study designed to demonstrate Business Analysis and System Analysis skills through the analysis and design of an HR Appointment Allowance Request Management System.
The project covers business requirements, process analysis, functional and non-functional requirements, use cases, wireframes, and database design.
Project Status: Conceptual case study — Analysis and Design only. No functional application has been developed or deployed.
